# 第10回 実践テスト

第10回で使う試験一式です。

## ファイル

| ファイル | 用途 | 誰が見るか |
|---|---|---|
| `exam1_questions.md` | 試験1(選択式15問)の問題 | 受講者 |
| `exam1_answers.md` | 試験1の解答と解説 | **講師のみ**(結果発表で使う) |
| `exam2_practical.md` | 試験2(Terraform実技4問)の問題 | 受講者 |
| `exam2_scoring.md` | 試験2の採点基準 | **講師のみ** |
| `exam_scoring_template.csv` | 採点用スプレッドシートの雛形 | 講師 |
| `1. question1/` 〜 `4. question4/` | 試験2の模範解答 | **講師のみ**(終了後に公開) |

> **★ `exam1_answers.md` / `exam2_scoring.md` / 模範解答は、
> 試験が終わるまで受講者に見せないこと。**
> このリポジトリは公開なので、当日までリンクを共有しないだけで十分です。

## 配点

| | 配点 |
|---|---|
| 試験1(選択式) | 15点(15問 × 1点) |
| 試験2(Terraform実技) | 100点 |
| **合計** | **115点** |

## 当日の流れ

| 時間 | 内容 |
|---|---|
| 25分 | 試験1(Google Form で提出) |
| 60分 | 試験2(GitHub のブランチに push) |
| 5分 | 休憩 |
| 15分 | 総まとめ |
| 15分 | 資格取得状況の共有 + 全体アンケート |

**実践テストだけで85分**あるので、総まとめは15分に圧縮しています。

## 講師の事前準備

1. **試験1を Google Form にする**
   `exam1_questions.md` の15問をフォームに写す。
   自動採点を設定しておくと当日が楽になる

2. **提出用の GitHub リポジトリを用意する**
   受講者が `exam/[自分の名前]` ブランチに push する。
   第7回で使ったアプリ用リポジトリとは**別に**作ること

3. **模範解答を1回通しで動かしておく**
   `4. question4/` を apply して、ブラウザで `Congratulation!!` が
   出ることを確認する。**所要時間も測っておくこと**

4. **採点用スプレッドシートを作る**
   `exam_scoring_template.csv` を Google スプレッドシートに読み込む

5. **受講者に「destroy は採点後」と伝える**
   実物確認をするので、試験直後に消されると採点できない
